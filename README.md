Repositório de Aulas — Python [Programação Estruturada e Orientada a Objetos]

Este repositório foi criado para disponibilizar aos alunos os arquivos, exemplos e exercícios desenvolvidos durante as aulas da unidade curricular de
Programação Estruturada e Orientada a Objetos (POO) e fundamentos de programação com Python do Curso Técnico em Desenvolvimento de Sistemas do SENAC MG. 
Conteúdo do repositório:

• Exemplos feitos em aula
• Exercícios práticos
• Desafios de lógica de programação
• Projetos desenvolvidos durante as atividades
• Materiais de apoio e revisões
• Códigos comentados para estudo

📌 Os conteúdos serão adicionados gradualmente conforme o andamento das aulas, organizados por temas, etapas ou datas.
